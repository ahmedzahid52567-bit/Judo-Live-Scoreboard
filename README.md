# Judo Live Scoreboard

A modern, responsive, and dynamic live scoreboard application for Judo tournaments. Built using React and Vite, this application provides an interactive interface for audiences and a comprehensive control panel for match operators.

## 🌟 Features

- **Live Audience Display**: A clean, high-visibility UI designed to be displayed on large screens for the audience.
- **Admin Dashboard**: A comprehensive control panel for tournament operators to:
  - Update scores dynamically.
  - Manage match timer (Start, Pause, Reset, and add/subtract time).
  - Declare match winners and trigger Golden Score (Overtime).
  - Add player names and college affiliations.
  - Upload custom player photos.
- **Dynamic Animations**: Includes confetti animations upon match completion to celebrate the winner.
- **Sleek UI/UX**: Built with modern aesthetics, smooth gradients, glassmorphism elements, and responsive design.

## 🚀 Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Custom Design System with responsive grid/flex layouts)
- **Icons**: `lucide-react`
- **Animations**: `canvas-confetti`

## 📦 Installation & Setup

1. **Clone the repository**:

   ```bash
   git clone https://github.com/ahmedzahid52567-bit/Judo-Live-Scoreboard.git
   ```

2. **Navigate into the project directory**:

   ```bash
   cd "Judo-Live-Scoreboard"
   ```

3. **Install dependencies**:

   ```bash
   npm install
   ```

4. **Start the development server**:

   ```bash
   npm run dev
   ```

5. Open your browser and navigate to the provided local URL (typically `http://localhost:5173/`).
